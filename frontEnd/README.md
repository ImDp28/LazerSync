# React + JavaScript + Vite

From this directory, run `npm ci`, then `npm run dev`.
Run `npm run build` to generate the production bundle in `dist/`.
Run `npm run lint` to check the source.

Set `VITE_API_URL=http://localhost:5000/api` in `.env` for a local backend.
See the root README and CONVERSION.md for setup and conversion details.
